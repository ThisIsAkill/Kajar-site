Each cell is one slice: the number is how many matched routines start in it, the colour is the highest level any of them has reached, and the gold bar is how much of the slice's bytes are already matched. Select a cell to see the routines inside, each with its level: matched, readable or verified.

Banks $C0, $C1 and $FD are where the work is; the other code banks are drawn too, still waiting for their first matched routine. For the region-by-region write-up see the Bank Map; for the totals see Progress.
