Welcome to ChronoRET, a byte-exact matching decompilation of Chrono Trigger (SNES, US 1.0).

The goal is hand-labeled 65816 assembly that assembles back to a ROM that is bit-for-bit identical to the original 1995 cartridge. Every matched function is verified with make diff before it is committed.

This project is not affiliated with or endorsed by Square or Square Enix in any way.

Methodology

Each function goes through four steps before it is marked matched:

  1. Disassemble — tools/disasm.py traces execution from a known entry point, tracking M/X flag state to decode operand widths correctly.
  2. Annotate — Labels, equates, and inline comments added by hand.
  3. Assemble — asar rebuilds the function; known assembler quirks (BRL offsets, STA addressing) are worked around explicitly.
  4. Verify — make diff compares the assembled output byte-for-byte against the original ROM. Only a clean diff gets committed.

Legal

Tools and source only — no ROM data, no extracted assets. To contribute or verify matches you need your own legally obtained copy of Chrono Trigger (SNES, US 1.0).
