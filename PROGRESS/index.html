$0C76 Per-Frame State Machine Cluster

The $0C76 cluster ($C0:0C76–$2DF0, ~8,600 bytes, 20+ blocks) is the per-frame state machine that drives door and switch tile-opening animations on the map. Sub_0C76 runs every frame from GameLoop_FrameBody; it dispatches to mode handlers (ModeE6/EC/EE/FA/FC) that advance a $7E:3000 tile table, compute VRAM write indices corner-by-corner, and trigger SPC audio cues. DefaultHandler covers the non-opening steady state. Sub_18D9 and its callees manage the full scene transition sequence triggered by the mode-dispatch path.
